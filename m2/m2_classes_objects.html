Creating a New Type

A class is a blueprint or template for creating objects.

  • The class defines data stored by its objects.
  • The class defines methods that operate on that data.
  • The collection of methods forms the class’s interface.
  • Calling the class creates an instance/object.
  • Objects are mutable: their state can change.

The __init__ Initializer

__init__ runs after a new object has been created.

class Person:
    def __init__(self, first, last, age):
        self.first_name = first_name
        self.last_name = last_name
        self.age = age

p = Person("Hellen", "Green", 24)
print(p.first_name, p.last_name)

p.age = 32
print(f"Age {p.age}")

For this call, __init__ initializes:

self.first_name = "Hellen"
self.last_name = "Green"
self.age = 24

__init__ establishes the object’s initial state.

Instance Methods and self

Method definitions are written inside the class.

class Person:
    def fullname(self):
        return f"{self.first} {self.last}"
  • An instance method operates on one particular object.
  • Its first parameter is conventionally named self.
  • In p.fullname(), Python binds self to the object referenced by p.
  • The method can read or change that object’s instance attributes.

Class Methods and cls

A class method operates on the class, not one particular object.

  • Use the @classmethod decorator.
  • The first parameter is conventionally named cls.
  • cls refers to the class.
  • A class method can read or change class attributes.
  • A class method can also create and return objects.

Complete Person Example — person.py

class Person:
    SCHOOL = "UVU" # Class attribute
    def __init__(self, first_name, last_name, age = 16):
        self.first_name = first_name
        self.last_name = last_name
        self.age = age
        
    # Instance/object method
    def fullname(self):
        return f"{self.first_name} {self.last_name}"
    
    def email(self):
        # hellen.green@uvu.edu
        return f"{self.first_name.lower()}.{self.last_name.lower()}@uvu.edu"
    
    def get_age(self): # self - > object itself
        return self.age
    
    ## setter
    def birthday(self):
        self.age += 1

    @classmethod
    def update_school(cls, new_school):
        cls.SCHOOL = new_school

    @classmethod
    def make_admin(cls):
        return Person("admin", "Admin", 35)
    
    def compare_age(self, other): # other is a Person
        if self.age > other.age:
            return self.first_name
        return other.first_name
    
    
    # Todo:
    @staticmethod
    def compare_age2(person1, person2):
        if person1.age > person2.age:
            return person1.first_name
        return person2.first_name        

    # Return a string
    # self -> person
    def __str__(self):
        return f"Pesron's name: {self.first_name} {self.last_name}, Age {self.age}"




def main():
    p1 = Person("Hellen", "Green", 24) # __init__
    print(f"Type: {type(p1)}")

    p1.first_name = "Hellen"
    p1.last_name = "Green"
    p1.birthday()
    print(p1)

    fullname = p1.fullname()
    Person.SCHOOL = "The U"

    print(p1.SCHOOL)

    Person.update_school("BYU")
    p5 = Person.make_admin()
    print(p5)

    p2 = Person("Will", "White", 18)

    older_person = p1.compare_age(p2)
    print(f"Older person (instance method): {older_person}")

    older_person = Person.compare_age2(p1, p2)
    print(f"Older person (static method): {older_person}")


    p3 = Person("Ben", "White")
    print(p3.SCHOOL)
    print(Person.SCHOOL)

if __name__ == "__main__":

__new__ vs __init__

When we write:

p = Person("Hellen", "Green", 24)

it looks like one step, but Python performs multiple steps behind the scenes.

  • Person(...) is the class call that starts object creation.
  • Python first invokes __new__.
  • __new__ creates and returns a new Person object.
  • Python then invokes __init__.
  • __init__ initializes the object’s state.

__new__ vs. __init__

new: Constructor

  • creates the object
  • returns the new object
  • runs before __init__
  • usually inherited from object

init: Initializer

  • initializes an already-created object
  • receives it as self
  • sets initial instance state
  • runs after __new__

Key idea: new creates the object; init initializes it.

Note

Many Python resources casually call __init__ the “constructor.” In this course, we use the more precise distinction: __new__ constructs the object and __init__ initializes it.

A Useful Error: p1 + p2

If we write:

print(p1 + p2)

Python raises a TypeError because Person does not define how + should work.

TypeError: unsupported operand type(s) for +: 'Person' and 'Person'

To make p1 + p2 meaningful, the class would need to define add. We will not add it here unless operator overloading is part of the lesson.

Class, Object, Attributes, and State

Class

A type or abstraction that defines attributes and methods.

Object / Instance

A unique object created from a class.

Attribute

A data element stored in an object.

State

The current values of an object’s attributes.

p = Person("Hellen", "Green", 24)
Object: p
first_name = “Hellen”
last_name = “Green”
age = 24

If p.age changes, the object is still the same object, but its state has changed.

Class Models… Method Models…

Class models…

  • a thing
  • a kind/type of thing
  • attributes of a thing

In a problem description, look for nouns.

Method models…

  • an action
  • an operation
  • an algorithm
  • behavior of a thing

In a problem description, look for verbs.

Recipe for Making a Class

  • Before writing code, identify the object’s attributes and behavior.
  • Choose an appropriate class name.
  • Choose appropriate data types for attributes.
  • Develop the class interface: a short list of methods.
  • Write a small use case showing how the class should be used.
  • Implement __init__, then add and test methods incrementally.
  • Add __str__ to make objects easier to inspect and debug.
  • Document the module, class, and methods.

Style Reminders

  • Class names use CamelCase
  • Method names use snake_case
  • Use module docstrings
  • Use class docstrings
  • Use method docstrings
