Some Object-Oriented Terms

  • Class: a type; an abstraction of related objects
  • Instance/Object: a unique object containing its own data
  • Attribute: a data element inside an instance
  • Method: a function that operates on an instance
  • Interface: the collection of methods defined by a class
  • State: the current values in the attributes of an instance
  • Instantiation: creating an object from a class

Class Variables and Methods

  • Class variables belong to the class, not each object.
  • All instances share the same class variable.
  • Class methods receive cls, not self.
  • They can be called from the class or from an instance.
  • Class methods can be used as alternative constructors.

__new__ vs. __init__

__new__: Constructor

  • Creates and returns a new object.
  • Runs before __init__.
  • Usually inherited from object.

__init__: Initializer

  • Initializes an object after it has been created.
  • Receives the new object as self.
  • Usually sets instance variables and initial state.

Order: __new__ creates the object → __init__ initializes the object.

Class Models… Method Models…

Class models…

A thing. A kind of thing. A type of thing. Attributes of a thing.

In a problem description, look for nouns.

Method models…

An action. An operation. An algorithm. Behavior of a thing.

In a problem description, look for verbs.

Recipe for Making a Class

  • Before writing code, think about behavior and attributes.
  • Choose an appropriate class name.
  • Develop a short list of methods available to users.
  • Write a short snippet that uses the new class.
  • These “use cases” can also be represented in UML.

Recipe for Making a Class

  • Choose appropriate data types for the attributes.
  • Fill in the skeleton with __init__ and __str__.
  • Complete and test the remaining methods incrementally.
  • Document your code as you go using module, class, and method docstrings.

Style Reminders

  • Class names use CamelCase
  • Method names use snake_case
  • Use module docstrings
  • Use class docstrings
  • Use method docstrings
